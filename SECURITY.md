# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's
private vulnerability reporting:
[Report a vulnerability](https://github.com/jacobhausler/hermes-pinned-folders/security/advisories/new).

Include the plugin version, which build you run (catalog `desktop/plugin.js` or
full `full/plugin.js`), your Hermes version, and the steps that show the problem.

## Supported versions

Only the latest release gets security fixes: the newest `vX.Y.Z` tag on
[Releases](https://github.com/jacobhausler/hermes-pinned-folders/releases), which is the
commit the Hermes plugin catalog entry pins. Older tags are not patched; update to the
latest release.

## What to expect

You get an acknowledgement within 7 days. Within 30 days you get a fix or a written
assessment of the report. Fixes ship as a new patch release and are credited to the
reporter unless you ask otherwise.
